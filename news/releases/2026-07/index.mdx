We are pleased to announce the July 2026 release of openRuyi.

In this release, openRuyi strengthens security across web and language runtimes, advances RISC-V platform integration, refreshes the kernel, desktop, Qt, ROCm, and build stacks, and adds substantial developer and publishing tooling.

{/* truncate */}

## Highlights

* **RISC-V toolchain and code generation**: Go now selects the RVA23 profile through `GORISCV64=rva23u64` for RVA23 builds while retaining a correct RVA20 fallback. GCC 15 gained a backported fix for incorrect NaN handling in auto-vectorized `fmin()` and `fmax()`.

* **Kernel and RISC-V platform integration**: We updated the mainline kernel from `7.1.2` to `7.1.4` and the LTS kernel from `6.18.34` to `6.18.39`. Patch and configuration refreshes broaden support across Sophgo, SpacemiT, T-Head, and UltraRISC systems, including PCIe, USB, storage, graphics, networking, ACPI, and board enablement.

* **RISC-V cryptography and runtime performance**: OpenSSL gained RISC-V backports for SHA-256 instruction scheduling and AES, SM4, and SM2 acceleration without a version change. jemalloc adds a RISC-V assembly path, while `rocr-runtime` corrects `zicbom` handling on RVA20 systems.

* **Desktop and graphical stack improvements**: We refreshed KDE Frameworks from `6.26.0` to `6.27.0`, Plasma from `6.6.5` to `6.7.1`, and Qt from `6.10.1` to `6.11.1`. The coordinated update advances the Wayland-facing desktop stack and introduces a Plasma-native login manager, while package-level fixes display startup behavior.

* **Accelerated computing and AI tooling**: We updated the ROCm stack to `7.2.4` and aligned it with LLVM 22. New Triton and timm packages expand distribution-managed AI compilation and computer-vision workflows.

* **Packaging, build, and virtualization infrastructure**: RPM moved from `4.20.1` to `6.0.1`, `obs-build` moved from `20250829` to `20260623`, and the release adds `virtiofsd`.

* **TeX and publishing stack integration**: The release adds TeX Live 2026 together with a separately packaged data tree. The integration splits collections into manageable subpackages and enables LuaJIT support on RISC-V.

## Security Updates

* The `python-aiohttp` was updated to `3.14.1`, fixing [CVE-2026-54279], [CVE-2026-34514], [CVE-2026-34517], [CVE-2026-54273], [CVE-2026-54275], [CVE-2026-34520], [CVE-2026-54277], [CVE-2026-34518], [CVE-2026-54280], [CVE-2026-34525], [CVE-2026-54278], [CVE-2026-34513], [CVE-2026-47265], [CVE-2026-54276], [CVE-2026-34993], [CVE-2026-34516], [CVE-2026-50269], [CVE-2026-34519], [CVE-2026-34515], [CVE-2026-22815], [CVE-2026-54274].

* The `python-authlib` was updated to `1.7.2`, fixing [CVE-2026-41425], [CVE-2026-44681].

* The `python-beaker` was updated to `1.14.1`, fixing [CVE-2013-7489].

* The `python-curl-cffi` was updated to `0.15.0`, fixing [CVE-2026-33752].

* The `python-django` was updated to `5.2.14`, fixing [CVE-2026-6907], [CVE-2026-35192], [CVE-2026-5766], [CVE-2026-35193], [CVE-2026-48587], [CVE-2026-6873], [CVE-2026-7666], [CVE-2026-8404].

* The Go update was updated to `1.26.5`, fixing [CVE-2026-39822] in `os.Root` path handling and [CVE-2026-42505] in TLS Encrypted Client Hello privacy protection.

* The NGINX update was updated to `1.31.3`, fixing [CVE-2026-42533].

* The `libssh` was update to `0.11.5`, fixing [CVE-2026-15370], [CVE-2026-59843], [CVE-2026-59844], [CVE-2026-59845], [CVE-2026-59846], [CVE-2026-59847], [CVE-2026-59848], [CVE-2026-59849], [CVE-2026-59850].

We continue to provide four editions for different scenarios: **Server**, **Container**, **Desktop**, and **Zero (BSP validation)**. You can download it from the [openRuyi release site](https://releases.openruyi.cn/creek/2026.07/rva23/).

For existing users, simpily do `dnf update` and you're done!
