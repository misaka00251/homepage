我们很高兴地宣布 openRuyi 2026 年 8 月版本正式发布。

本次发布以安全修复为重点集中更新了软件包，推进了 RISC-V 与 RVA23 集成，扩展了云原生和加速计算能力，并更新了内核、工具链、科学计算软件栈与 KDE 桌面环境。

## 亮点

* **工具链、运行时与构建基础设施**：我们将 GCC 16 从 `16.1.0` 更新至 `16.2.0`，将 glibc 从 `2.43` 更新至 `2.44`，并将 Rust 从 `1.95.0` 更新至 `1.97.1`。发行版工程方面，本次更新还减少了对 LLVM 静态库的不必要构建依赖，并修复了 glibc 迁移带来的兼容性问题。

* **内核与核心平台更新**：我们将主线内核从 `7.1.4` 更新至 `7.2`，并将长期支持内核从 `6.18.39` 更新至 `6.18.46`。本次更新还引入了基于 `kernel-team-tools` 的内核制作与转换流程：围绕上游基线跟踪、筛选和整理两条内核分支的下游改动，生成有序补丁集以及面向 x86_64、通用 RISC-V 和 RVA20 的内核配置，并将其发布为可供 RPM 构建复用的归档。初始迁移阶段共转换和核对了主线内核的 244 个补丁、LTS 内核的 560 个补丁及两套多架构配置。刷新后的内核进一步扩展了对 SpacemiT、Sophgo、T-Head 和 UltraRISC 等 RISC-V 平台的支持，涵盖 PCIe、USB、存储、网络、显示及其他 SoC 集成方向。Dracut 也从 `111` 更新至 `112`，并纳入了一项改善其与 glibc `2.44` 兼容性的上游修复。

* **RISC-V 与 RVA23 集成**：LLVM 22 修复了 RISC-V 上的向量化崩溃，以及栈探测过程中寄存器被意外覆盖的问题；OpenBLAS 现在会在 RVA23 构建中选择 ZVL128B 目标。Rust QuickJS 绑定也新增了对 `riscv64gc` 和 `riscv64a23` 的支持，在保持共用 LP64D ABI 不变的前提下补齐了特定于架构的支持缺口。

* **云原生、容器与存储**：openRuyi 新增 Kubernetes `1.35.5` 和 containerd `2.3.3`，并补充了构成可用云原生软件栈所需的网络、存储、CRI 和集群验证工具。

* **科学计算与 HPC 能力扩展**：本次发布大幅扩展了以 Jupyter 和 Dask 为基础的 Python 科学计算环境，补齐了分布式数据处理、数值计算、地理空间计算、天文计算和图像分析等工作负载所需的依赖。OpenMPI `5.0.10` 及其 PMIx 和 PRRTE 运行时组件也加入了发行版，为分布式计算和高性能计算提供了 MPI 软件栈。

* **人工智能与加速计算**：本次发布新增 ROCm `7.2.4`，并在 PyTorch `2.13.0` 中启用了 ROCm 后端。vLLM 以 CPU 和 ROCm 两种构建变体加入 openRuyi，相关编译器与计算机视觉依赖也同步完成了 ABI 和 multibuild 适配。

* **桌面与图形软件栈改进**：KDE Frameworks 从 `6.27.0` 更新至 `6.28.0`，KDE Plasma 则从 `6.7.1` 更新至 `6.7.4`。GIMP `3.2.0` 及其图像处理依赖栈也加入了发行版，进一步丰富了面向用户的图形软件选择。
