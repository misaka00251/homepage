# 开源之夏

openRuyi 欢迎高校学生参与开源之夏 (Open Source Promotion Plan, OSPP)。

开源之夏为高校学生提供在社区导师指导下参与开源项目并作出贡献的机会。openRuyi 通过以下两种模式参与开源之夏:

* **经典模式 (Classic Track):** 导师提出具体的项目任务，学生根据自己的兴趣和技能选择项目并提交申请。

* **领航模式 (Pioneer Program):** 社区提出较为宽泛的技术方向，学生从中确定具体问题并提出解决方案。

两种模式均采用持续开放的安排，不设统一的申请期或开发期。每个入选项目按照各自的时间安排开展。

## 学生参与说明

申请前，请阅读[开源之夏组织指南](https://docs2026.summer.ospp.ac.cn/help/CommunityGuide)和[开源之夏常见问题](https://docs2026.summer.ospp.ac.cn/help/FAQ)。还应根据计划参与的模式阅读相应[学生指南](https://docs2026.summer.ospp.ac.cn/help/student%20guide)和[领航模式指南](https://docs2026.summer.ospp.ac.cn/help/Pioneer-guide)。

### 参与资格

开源之夏面向全球年满 18 周岁的高校在校学生。学生在项目开发期间必须保持在读状态。

已经获得硕士或博士研究生录取资格但尚未正式入学的学生，可以提供录取通知书及其他所需证明材料。

参与者不得同时以学生和导师两种身份参与开源之夏。

同一时间，学生只能申请或承担一个开源之夏项目。申请被拒绝或当前项目完成后，可以申请其他项目。

用于向项目仓库提交贡献的账号必须公开。该账号的公开邮箱地址必须与开源之夏报名时提供的 Git 邮箱地址一致。

### 准备申请

申请开源之夏项目不要求具备丰富的开源开发经验。但是，熟悉项目所使用的编程语言、RISC-V 或目标代码库，有助于准备更完善的项目申请。

申请前:

* 阅读项目文档和贡献指南。

* 了解感兴趣的项目所涉及的代码。

* 与意向导师讨论项目范围、对问题的理解以及计划采用的解决方案。

* 在有助于熟悉项目及其开发流程的情况下，参与正常的社区贡献。

准备申请期间，可以正常参与 openRuyi 社区贡献。但是，在组委会正式公布入选结果前，不得开始实施 OSPP 申请中提出的项目工作。入选前完成的工作不会计入项目最终考核。

### 查找项目

可以在 [openRuyi OSPP 组织页面](https://summer.ospp.ac.cn/org/orgdetail/59ab01aa-4c76-4f61-834f-ac4c636267bf)查看 openRuyi 发布的项目。

提交申请前，我们建议先与项目导师沟通。提前沟通有助于了解项目要求、确定合理的项目范围并完善申请方案。

如需联系导师，请在 [openRuyi OSPP 仓库](https://github.com/openRuyi-Project/ospp/issues)中对应的 Issue 下留言。如果项目介绍中提供了导师的邮箱地址，也可以通过邮件联系导师。

## 导师参与说明

参与导师工作前，请阅读[开源之夏组织指南](https://docs2026.summer.ospp.ac.cn/help/CommunityGuide)和[开源之夏常见问题](https://docs2026.summer.ospp.ac.cn/help/FAQ)。还应根据参与的模式阅读相应[导师指南](https://docs2026.summer.ospp.ac.cn/help/mentor%20guide)和[领航模式指南](https://docs2026.summer.ospp.ac.cn/help/Pioneer-guide)。

导师负责帮助学生理解项目、制定切实可行的开发计划、审查学生提交的工作，并协助解决开发期间遇到的技术问题。

我们将在本站另行发布面向 openRuyi 导师的详细指南。

如对 openRuyi 参与开源之夏有其他问题，请通过 [contact@openruyi.cn](mailto:contact@openruyi.cn) 联系我们。
